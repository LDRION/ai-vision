# AI Vision — агент, который видит экран и доводит задачу до конца

Computer-use агент для Windows: смотрит на экран, решает, что сделать, и работает мышью и клавиатурой, как человек, — там, где у программы нет API. Пример: «зайди в почту и открой последнее письмо». Курсор движется по-человечески: дуга, шум и коррекция промаха, как в [MacroRec](https://github.com/LDRION/macrorec).

Поверх движка экрана — **ИИ-компания**: агенты по отделам, оркестратор, инструменты и 24/7-пульс, который сам ставит задачи (см. [ORCHESTRATION.md](ORCHESTRATION.md)).

Около 10 500 строк Python, 3 500 строк тестов (123 офлайн-теста без сети и мыши), десктопный и веб-лаунчер.

## Где здесь ИИ-инженерия

| Задача | Как решено |
| --- | --- |
| Модель по голому скриншоту промахивается на сотни пикселей (замер: 0 попаданий из 7) | **Set-of-marks**: элементы с точными рамками берутся из дерева доступности Windows (UI Automation) и OCR, на скриншоте рисуются номера. Модель называет номер, точку клика даёт рамка — 5 из 5, ошибка до 1,4 px |
| Иконки без подписи | Сетка с линейками в экранных пикселях → второй запрос с увеличенным ×4 фрагментом: ошибка 20–32 px → 2–5 px |
| Модель может отвечать «вслепую», не увидев картинку | Проверка зрения: на разметке печатается случайный код, которого нет в тексте; не вернула код — координаты отбрасываются |
| Дорогой большой вызов на каждый простой шаг | Ярусы «мозга»: рефлекс по тексту без модели → локальная модель Ollama (`qwen2.5:7b`) выбирает элемент по смыслу → облачная модель (Siberi или Claude) для планирования |
| Агент бьётся в одну и ту же стену | История шагов с реакцией экрана, лестница способов (наведение → перетаскивание → двойной клик → удержание → клавиатура), запрет на третий повтор бесполезного действия |
| Каждый раз учиться заново | После задачи модель разбирает прогон и пишет 0–3 урока, привязанных к приложению; уроки подмешиваются в промпт следующих задач (замер: 5–7 шагов → 3) |
| Повторяемые сценарии не должны стоить LLM-вызова на шаг | Удачный прогон сохраняется **рецептом** и в следующий раз проигрывается быстрым путём; не сошлось — агент доигрывает полным разбором |
| Чужие секреты на экране | Ключи и пароли маскируются в тексте экрана до того, как он уйдёт модели |

Мозг подключается одной переменной: [Siberi](https://github.com/LDRION/siberi) (моя LLM-платформа; по умолчанию её локальный драйвер) или Claude через Anthropic API (`AV_BRAIN=claude`). Живой индекс экрана — встроенная копия [screen-retina](https://github.com/LDRION/screen-retina).

```
          ┌──────────────────────────────────── история шагов + реакция экрана ◄──────────────────┐
          ▼                                                                                        │
скриншот ─► элементы с точными рамками ─► разметка ─► Siberi ─► действие ─► траектория ─► мышь/клавиши ─► ждём, пока экран успокоится
            UI Automation + OCR Windows    номера+сетка   ▲  (выбор)   click/drag/hover/   формат .rec
                                           +курсор        │            long_press/type/key/
                                                          │            scroll/wait/done/fail
                          подсказки пользователя ─────────┤
                          уроки прошлых задач (experience/lessons.json) ◄── разбор опыта после задачи
```

## Самокоррекция, подсказки и обучение на опыте

- **Лестница способов.** Если клик не сработал, Siberi по истории видит «экран НЕ изменился» и меняет способ по лестнице из промта: наведение → перетаскивание (зажать ЛКМ и вести) → двойной клик → удержание → правый клик → клавиатура → прокрутка.
- **Запрет на повтор.** Действие, которое дважды ничего не дало, третий раз не исполняется («ОТКЛОНЕНО»). Siberi вынуждена искать другой путь, а не биться в стену.
- **Подсказки человеческим языком.** `--hint "зажми карточку и тащи правее, примерно в середину"` или прямо в тексте цели. Подсказки главнее догадок и уроков. Разговорные слова переводятся в действия: «зажал и повёл» → drag, «наведи» → hover, «подержи» → long_press. Направление «правее» — это сектор поиска осмысленной цели (колонка, слот, конец шкалы), а не сдвиг на N пикселей. «Сюда» отсчитывается от курсора: его позиция есть в запросе и отмечена на скриншоте.
- **Застряли — спросим.** Если агент сдался, застрял или кончились шаги, он спрашивает в терминале: «Подскажи, как это сделать». Вы отвечаете, у вас 3 секунды вернуться в окно, и он продолжает с подсказкой.
- **Обучение.** После задачи Siberi разбирает историю: что не сработало, что сработало вместо этого, какая подсказка помогла. Получаются 0–3 урока, привязанные к приложению («Трекер», «Яндекс Почта»), без дублей. В следующих задачах уроки приложения из активного окна подмешиваются в промт. Объяснили один раз — дальше агент знает сам. Уроки лежат в `experience/lessons.json` и в git не попадают.

## Лаунчер

`python -m aivision` (без аргументов) открывает лаунчер в минималистичном чёрно-бело-сером стиле. Всё в одном окне: слева сайдбар сценариев, справа вкладки **Редактор / Схема / Запись** — отдельные окна больше не плодятся.

- **Сценарии** копятся без ограничений. У каждого: цель-промт, подсказки, браузер (свой или «по умолчанию»), стартовый URL, приватное окно, монитор, скорость, шум траектории, уточнение иконок, обучение, запись экрана. Хранятся в `scenarios/` (в git не попадают).
- **Управление в сайдбаре.** На выбранном сценарии — кнопки ↑ ↓ (переставить), ⧉ (дублировать), 🗑 (удалить). Двойной клик по строке — переименовать на месте.
- **Перенос кусочка.** В карточке подсказок есть «＋ взять из…» — дописывает подсказки другого сценария (без дублей).
- **Очередь.** Мышь и клавиатура физически одни, поэтому «Запустить» ставит сценарий в очередь: они идут один за другим. В сайдбаре видно «● идёт…» и «⏳ в очереди (N)», лишний можно убрать.
- **Браузеры** берутся из реестра Windows. Браузер по умолчанию задаётся в сайдбаре, у сценария можно выбрать другой.
- **Монитор «Авто».** Если задан стартовый URL, браузер встаёт развёрнутым на экран без лаунчера: агент работает на одном мониторе, а ты смотришь живую «Схему» на другом. Без URL агент берёт экран окна, в которое ты переключился за 3 секунды отсчёта.
- **«Схема»** — пошагово: экран на каждом действии (разметка или чистый экран), что сделано и почему. Во время прогона заполняется вживую. Шаг можно поправить рукой: тип действия, точка клика (кликом по картинке), текст, клавиши, шум. Сохранить и проиграть только этот шаг.
- **«Запись»** — видео прогона с таймлайном как в Clipchamp: превью, курсор, дорожка с отрезками «Siberi думает» и «действие», маркеры, перемотка.

### Запуск и сборка

- **Разработка (всегда свежий код).** Двойной клик по `AiVision.vbs` (или `python dev_launcher.py`, или `dist\AiVisionDev.exe`) запускает приложение из живого кода и сам перезапускает окно, как только сохранишь любой `.py` в `aivision/`. Пересобирать ничего не нужно.
- **Автономный exe.** `build.bat` собирает `dist\AiVision\AiVision.exe` — снимок кода без консоли, переносится на машину без Python. Это снимок: обновляется только пересборкой.

```powershell
build.bat        # соберёт AiVisionDev.exe и AiVision.exe
```
Рядом с exe положи `.env` с `SIBERI_API_KEY`; папки `runs`, `scenarios`, `experience`, `recipes` создаются там же.

### Службы поднимаются сами

Отдельно ничего запускать не нужно. Лаунчер (оба), оркестратор (`aivision.orchestrate_cli`), пульс с `--execute` и любой прогон на экране сами поднимают фоном (`aivision/services.py`):

- **Screen Retina**: живой индекс экрана для курсора (элементы с рамками за ~20 мс, журнал изменений, ожидание «экран успокоился»). Работает **встроенная копия** `aivision/vendor/retina` на порту **8766**, а не внешний проект [screen-retina](https://github.com/LDRION/screen-retina): его можно менять отдельно, AiVision это не затронет. Retina — процесс-ребёнок в Job Object: закрыл или уронил лаунчер, и она гаснет сама. Журнал событий и лог лежат в `company/state/retina/` (вне git, старше 3 дней удаляются).
- **Ollama**: локальная модель `qwen2.5:7b` выбирает элемент по смыслу. Не запущена — запускаем `ollama serve` и заранее грузим модель в видеопамять.

В лаунчере статус виден в строке состояния («👁 Retina работает · 🧠 Ollama готова»). Нет службы — AiVision работает по-старому, медленнее. Переключатели: `AV_RETINA=0`, `AV_LOCAL_BRAIN=0`; `AV_RETINA_URL=http://127.0.0.1:8765` — работать со своей внешней Retina (например, dev-версией) и встроенную не запускать.

Обновить встроенную копию из внешнего проекта, осознанно и с тестами:

```powershell
python tools/vendor_retina.py                  # копия + паспорт VENDORED.md (коммит источника)
python -m pytest tests/retina -q; python -m tests.test_offline
```

## Почему не «сетка до сотых пикселя»

- Курсор ставится в целые пиксели, дробные координаты физически некуда применить.
- Модель ужимает картинку. Линии чаще ~100 px превращаются в шум поверх кнопок, а пиксели модель не считает: она читает подписи.
- Точность даёт не сетка, а **точные рамки с нашей стороны**. Дерево доступности Windows (UIA) и OCR дают координаты кнопок с точностью до пикселя. ИИ называет номер элемента, точку клика берём из рамки.
- Сетка с линейками в экранных пикселях и шаг zoom ×4 нужны только как запасной путь для иконок, которых нет ни в UIA, ни в OCR.

## Запуск

```powershell
pip install -r requirements.txt          # или локально: pip install -e .\macrorec
# .env:  SIBERI_API_KEY=...
python -m aivision "зайди в почту и открой последнее письмо"   # агент по шагам до цели (до 15 шагов)
python -m aivision "нажми Войти" --once                         # одно действие
python -m aivision "открыть Маркет" --dry-run                   # план одного действия, курсор не трогаем
python -m aivision "нажать Найти" --image shot.png             # план по готовому скриншоту
python -m aivision "перенеси карточку в Готово" --hint "зажми карточку и тащи правее"
python tests\test_offline.py                                    # всё без сети и без мыши
python tests\bench_tasks.py                                     # живая Siberi проходит задачи на виртуальном экране
python tests\bench_tasks.py --learn archive_card                # та же задача дважды: учится ли на опыте
python tests\live_input_selftest.py                             # живой ввод на ОС: клик, ввод, drag, удержание… (двигает мышь)
python tests\live_e2e.py                                        # сквозной прогон в настоящем браузере (двигает мышь)
python tests\bench_siberi.py                                    # точность наведения на синтетической странице
```

После старта есть 3 секунды (`--delay`), чтобы переключиться в нужное окно. **Остановить агента — сдвинуть мышь рукой.** Пока работает агент, компьютером пользоваться нельзя: мышь и клавиатура заняты. Игры с захватом мыши (например, WoW) держат курсор в центре экрана, и агент сразу остановится.

Каждый запуск сохраняется в `runs/<время>/step_NN/`:

- `screen.png` — исходный снимок;
- `marked.png` — что видела Siberi;
- `prompt.txt` и ответы модели;
- `zoom.png` — увеличенный фрагмент для шага уточнения;
- `action.rec` — действие в формате MacroRec, открывается в его редакторе.

Итог всего прогона лежит в `result.json`.

## Страховки

- **Проверка зрения.** Сверху на разметке печатается случайный код, которого нет в тексте запроса. Если модель не вернула его, она отвечала вслепую. Выбор номера из списка тогда принимаем (рамка точная), а координаты отбрасываем и спрашиваем заново.
- **Экран поменялся, пока Siberi думала.** Если область цели или активное окно изменились, действие не выполняется, решение принимается по новому снимку.
- **Ввод привязан к окну.** Если фокус ушёл в другое окно посреди ввода, клавиатура сразу обрывается: текст не попадёт не туда.
- **Перехват мыши.** Если пользователь сдвинул мышь во время движения или между шагами, агент останавливается.
- **Застревание.** Если 3 шага подряд экран не реагирует, агент останавливается. Siberi видит реакцию на каждый шаг и сама пробует другой путь.
- **Опасные действия.** Пароли, коды из СМС, капча, оплата и удаление приводят к `fail` с объяснением. Агент их не вводит и не подтверждает, если цель прямо этого не требует.

**Наведение** (`tests/bench_siberi.py`, синтетическая главная Яндекса 1920×1080):

| Вариант | Попаданий | Ошибка от центра |
|---|---|---|
| Голый скриншот, Siberi сама называет координаты | 0/7 | 117–885 px |

**Обучение на опыте** (`bench_tasks.py --learn archive_card`, одна задача дважды с общей памятью):

| Прогон | Шагов | Время | Что происходило |
|---|---|---|---|
| №1, опыта нет | 5–7 | 44–76 с | правый клик — нет, наведение — нет, двойной клик — открылось окно → «Архивировать». Урок [Трекер]: «Двойной клик по карточке открывает её меню, где кнопка архивации» |
